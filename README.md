- 改為「海報舞台」式首頁：完整活動圖置中放大，不再使用左右欄位。
- 首頁主視覺下方配置大型領取按鈕，讓操作焦點集中。
- 中段改為深藍色大字宣言區與橫向活動文字跑馬燈。
- 領取流程改為編輯式橫列編號，不使用三張卡片。
- 使用薄荷綠、深藍、亮黃與珊瑚橘，營造貼圖活動視覺。
- 手機版改為直向海報、清楚步驟與底部固定領取按鈕。
- 完整活動主視覺已內嵌於 HTML，並另保留原始 PNG。
